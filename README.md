# Layers

Совместный дизайн-инструмент в реальном времени, вдохновлённый Figma. Сделан, чтобы разобраться, как такие инструменты устроены изнутри — от presence и живой синхронизации фигур через WebSocket до авторизации и рендеринга канваса.

## Возможности

- Канвас-редактор с фигурами (прямоугольник, эллипс, текст) на Fabric.js
- Совместная работа в реальном времени через WebSocket — видно других пользователей и мгновенные изменения фигур
- Дашборд проектов — создание, переименование, удаление
- Авторизация через httpOnly JWT-куку

## Стек

- **Frontend:** Next.js (App Router), TypeScript, Redux Toolkit, Tailwind CSS, Fabric.js
- **Backend:** Express, WebSocket (`ws`), PostgreSQL, Redis
- **Инфраструктура:** Docker Compose для локального Postgres/Redis

## Структура проекта

```
apps/
  web/      # Next.js фронтенд
  server/   # Express бэкенд + WebSocket-сервер
packages/
  shared/   # Общие TypeScript-типы
```

## Запуск

```bash
docker-compose up -d      # поднять Postgres и Redis
npm install
npm run dev:server        # бэкенд на :4000
npm run dev:web           # фронтенд на :3000
```

## Backend

`apps/server` — самостоятельный сервис на Express, отвечающий за авторизацию, работу с данными и синхронизацию в реальном времени. Frontend обращается к нему не напрямую, а через BFF-прокси на стороне Next.js — это скрывает JWT от клиентского JS и держит все обращения к бэкенду за httpOnly-кукой.

### Архитектура

Сервис разбит на модули по доменам, каждый со своим слоем routes → service → repository:

```
src/
  auth/        # регистрация, логин, JWT, middleware проверки токена
  projects/    # CRUD проектов, проверка владельца
  shapes/      # CRUD фигур на канвасе
  db/          # подключение к Postgres, миграции
  ws.ts        # WebSocket-сервер: presence и live-обновления фигур
  swagger.ts   # OpenAPI-документация
  index.ts     # точка входа, поднимает HTTP + WS на одном порту
```

- **REST API** — Express-роуты для auth/projects/shapes, каждый эндпоинт проверяет владельца проекта перед доступом к данным.
- **WebSocket** — поверх того же HTTP-сервера поднят `ws`-сервер с комнатами по `projectId`: при подключении клиент авторизуется той же JWT-кукой, попадает в комнату своего проекта и получает presence других участников и события изменений фигур в реальном времени.
- **PostgreSQL** — основное хранилище: пользователи, проекты, фигуры.
- **Redis** — поднят в docker-compose для дальнейшего использования (кэш/очереди по мере роста сервиса).
- **Heartbeat** — сервер пингует WS-клиентов каждые 30 секунд и закрывает мёртвые соединения.

### API

Документация эндпоинтов доступна через Swagger UI на `/api-docs` после запуска сервиса.

### Запуск отдельно

```bash
npm run dev:server     # ts-node-dev с авто-рестартом на :4000
npm run migrate         # прогнать миграции Postgres
```
